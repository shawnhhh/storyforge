## 数据隔离及晚上回归边界

全部小说、设定与章节均为测试生成的虚构数据。测试创建和清理临时 SQLite 与备份目录，未访问真实小说数据库或备份，也没有调用付费 API。E2E 清除继承的 StoryForge AI/各提供商配置，在 Vite 与测试后端中不加载本地 `.env`；测试不需要真实密钥。

未连接或同步用户 Mac，未执行 macOS Safari/Firefox、真实提供商或本地模型端点的手工验证。晚上同步分支、完整回归及可视化检查步骤见 [工作台使用与 Mac 回归说明](ai-workbench.md)。重点检查 Safari 原生 dialog、选区/滚动、中文输入、撤销/重做、关闭与取消、来源截断提示。

模型目录由服务端环境管理，本次生成参数不跨窗口持久化；变更概览不是逐词最小 diff；引用只发送预算内片段，规划工作区版本变化可能要求刷新预览。进程预算重启会重置，未知报价没有美元费用保证；配置报价及 UTF-8 保守估算不能替代服务商账单限额。实际模型质量、价格及额外推理计费不在 Mock 测试保证范围内。Draft PR 应在 Mac 完整回归后再安排后续审阅与分支关系调整。
