# 第一版 AI 辅助写作

后续工作台迭代（依赖未合并的 PR #7）新增逐项上下文、模型目录、预算和对比撤销，见 [AI 写作工作台说明](ai-workbench.md)。本页保留第一版基础流程。

本模块沿用 React、TypeScript、Express、SQLite 架构，集成现有 Tiptap 章节编辑器。AI 请求不会写入数据库；只有用户接受生成结果后，编辑事务才进入原有章节自动保存队列。不增加数据库表或迁移。

## 本地配置

需要 Node.js 24。在项目根目录的本地 `.env` 配置以下服务端变量；可以从 `.env.example` 复制。已有 `.env` 时只添加变量，避免覆盖现有路径。

```dotenv
STORYFORGE_AI_API_KEY=在此填写自己的密钥
STORYFORGE_AI_BASE_URL=https://api.openai.com/v1
STORYFORGE_AI_MODEL=gpt-4o-mini
STORYFORGE_AI_TIMEOUT_MS=60000
```

接口地址是 OpenAI 兼容 API 的基础路径，后端追加 `/chat/completions`，不要重复填写该后缀。默认模型只是配置示例，须确保你的服务提供该模型。超时允许 100–120000 毫秒。

远程接口必须使用 HTTPS；本机模型支持 `http://127.0.0.1:端口/v1`、`http://localhost:端口/v1` 或 IPv6 回环地址。禁止 URL 中的用户名、密码、查询参数和片段；不跟随重定向，避免将认证信息发送到其他服务。未来可通过 `AiProvider` 实现其他协议；本地 OpenAI 兼容服务已可使用相同实现，第一版仍要求填写服务接受的非空密钥。

`.env` 已被 Git 忽略。macOS/Linux 执行 `chmod 600 .env`，Windows 使用文件访问权限将其限制为当前用户。不要使用 `VITE_` 前缀，不要把密钥填写到小说正文、人物资料、截图或文档中。服务端变量只由 `server/src/modules/ai/config.ts` 读取，前端没有密钥输入或存储功能，也不将密钥写入 SQLite、备份或日志。配置文件以本机用户权限保护，并非加密保险库。

运行 `npm ci`，然后 `npm run dev:all`。更改 AI 配置后重启后端。没有密钥时，AI 窗口明确提示配置方法，其他写作、自动保存和管理功能正常工作。

## 使用方式

1. 打开章节，把光标放到插入处，或选择需要处理的正文，点击工具栏「AI 辅助」。专注模式中同样可用。
2. 选择操作，可填写文风、节奏、叙述方式和人物口吻要求。
3. 展开「查看将发送的正文片段」，确认上下文。可选勾选「附带本小说已保存的人物、世界观与大纲摘要」。默认不附带资料。
4. 点击「生成预览」才发送请求。检查生成内容及 token 用量提示，可重新生成、放弃或取消请求。
5. 点击「接受并插入」或「接受并替换选文」才修改正文；之后自动保存，仍可使用编辑器撤销。请检查自动保存状态，失败或冲突按现有流程处理。

| 操作 | 输入及接受行为 |
| --- | --- |
| AI 续写 | 使用附近前后文与选文；在选文末尾插入，无选文时在原光标位置插入，不删除选文 |
| AI 润色 | 必须选择正文；保持原意和人物口吻，确认后替换原选区 |
| AI 扩写 | 必须选择正文；增加描写，确认后替换原选区 |
| AI 改写 | 必须选择正文；按填写要求调整文风、节奏与表达，确认后替换原选区 |
| AI 灵感 | 根据章节和可选资料提供建议；只供阅读，不提供自动替换按钮 |

## 数据范围与安全边界

- 仅发送当前选文（最多 6000 字符）、选区/光标前最多 6000 字符、后最多 3000 字符，以及最多 1000 字符的写作要求。超长章节使用附近片段；选文本身超长则要求缩小选区，不静默截断选文。
- 勾选资料后，在服务端读取同一本小说已保存的简介、人物性格/身份/备注、世界观描述、总纲/分卷大纲及关联当前章节的章节大纲。摘要最多 6000 字符；各类别独立截断，长资料可能不完整。不会发送其他小说、其他章节正文、备份或密钥。
- 生成期间不改变编辑器文档、选区或滚动容器，不重建编辑器；关闭后回到原滚动位置并恢复编辑焦点。接受时以 ProseMirror 事务映射光标和选区到新文档；保留选区外的内容与格式。生成文本按纯文本插入，换行成为段落，不执行 HTML 或脚本，选文内部原格式会被生成的纯文本替换。
- 若快照之后正文有任何变化，预览不可接受，须关闭后重新生成。切换章节或离开模块会销毁窗口并中止请求，旧响应不能写入新章节。预览未接受时刷新页面会丢失预览，不影响原正文。
- 请求仅由回环地址后端代理，沿用 Host/Origin、JSON 和服务代际校验。每个服务最多两个并发 AI 请求。响应不缓存，不记录请求/结果或上游错误正文，不自动重试付费请求。认证、限流、超时、无效响应均返回可操作的中文错误。
- 取消、关闭或超时会中止上游 HTTP 请求；服务商可能已经开始生成并计费，无法保证远端计算立即停止。token 统计以服务商返回为准，缺失时显示未知；不估算价格。输出上限为 2000 tokens，达到限制会提示可能不完整。
- 配置模型服务代表你选择将生成时确认的素材发送给该服务；素材在服务商的留存、训练和计费政策由该服务商控制。开发与测试全部使用虚构数据和 Mock，不调用真实付费 API。模型的原意保留与人物风格是提示要求，仍需作者审阅后接受。

## 架构与验证

共享协议：`shared/contracts/ai.ts`；服务端：`server/src/modules/ai/{config,provider,routes}.ts`；前端：`src/features/ai/`。Provider 接口接收已限定的创作输入、可选设定摘要及 AbortSignal，返回纯文本、用量与结束原因。`GET /api/ai/status` 仅暴露是否配置、模型名称与提示；`POST /api/ai/generate` 不写正文。

```sh
npm run lint
npm run typecheck
npm run build
npm test
npx playwright install --with-deps chromium
npm run test:e2e
```

已有 Chromium 时可用 `E2E_CHROMIUM_PATH=/路径/chromium npm run test:e2e`。E2E 启动器明确清空 AI Key，不读取 `.env`，创建独立临时数据库与备份目录并清理。AI 浏览器测试 Mock `/api/ai/*`；接口测试使用本机 HTTP Mock 服务验证真实代理协议、超时与断连取消。测试报告见 [ai-writing-test-report.md](ai-writing-test-report.md)。
