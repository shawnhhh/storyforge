# AI 章节一致性审阅

在正文工具栏选择“一致性审阅”，检查人物身份、性格、关系，世界观规则，以及章节逻辑和剧情衔接。结果仅供作者核实，不修改正文，不提供应用或替换按钮，不写入数据库或浏览器存储。

## 使用与验收

1. 打开任意测试作品的章节，点击“一致性审阅”。未配置服务端 AI Key 时会有提示；其他写作功能正常，仍可预览上下文。
2. 在复用的模型配置中心选择模型与参数。按需勾选本作品资料，最多 8 项，复用原有引用长度限制与截断提示。未选择其他章节时，不发送其他章节正文，也没有自动摘要或全书读取入口。
3. 点击“预览发送上下文”。此操作不调用模型、不预留 AI 预算。核对完整章节快照、所选引用、系统指令、模型参数、保守 token 与费用估算；勾选同意后，才能点击“确认并开始审阅”。
4. 检查“有引用依据的疑似冲突”和“不确定建议”。每项包含问题、原文依据和修改建议。无有效依据的冲突会降级；原文存在不等于模型判断正确，仍须作者核实。
5. 修改模型参数或引用后，旧确认失效，需要重新预览确认。后台资料变化或删除会在发送前被拒绝。正文变化会终止请求并标记快照失效。
6. 取消、关闭或切换章节后，迟到的响应不能展示为新结果。取消重审或预算错误时保留上一份结果；设置变化时标注旧结果。关闭后清除本次审阅状态。
7. 验证正文、撤销历史、选区、滚动位置与编辑器实例不受审阅影响。分别在浅色、深色和窄屏下验收。

手工验收若需要模型响应，应使用本地 Mock 服务与虚构素材；本次自动化测试没有调用真实付费 AI。

## 实现边界

- `POST /api/ai/review/preview` 校验输入、解析明确选择的引用，返回实际 messages、来源、确认指纹与估算；不调用 Provider。
- `POST /api/ai/review` 重算指纹，核对章节快照、引用版本、模型配置与参数，再进入已有 Provider、费用、请求数、token 和并发限制。与 AI 写作共用同一预算账本和两条并发槽位。
- 指纹不包含或返回密钥，不持久保存正文、模型响应或确认状态。API 响应沿用 `Cache-Control: no-store`。错误不透传上游信息。
- 当前章节最多 40000 字符，超出会明确拒绝，绝不静默截断；预算也可能拒绝较短章节。引用沿用 256–12000 字符总预算和均分规则。估算按实际发送 messages 的 UTF-8 字节计算。
- 模型须返回有界 JSON。服务端核对每条引文是否逐字存在于指定且已发送的来源；未知来源、伪造或缺失引文不会作为有效依据。只有至少两段不同原文、且没有失效引文的条目能保留为疑似冲突；不确定建议永不自动升级。
- 引文校验验证来源，不验证语义。模型判断可能错误或遗漏；未报告问题不表示全书无矛盾。截断引用只代表所示片段。
- 没有数据库迁移，没有引入未合并的时间线或回收站代码。正文保存队列、专注模式、草稿保护和撤销流程没有改动。

## 自动化覆盖

服务端专项：输入边界、完整发送与选择隔离、确认与版本绑定、跨作品和失效引用、原文引证与降级、共享请求/费用/token 预算、并发、取消、超时、无密钥、无效响应、密钥回显及只读保护。

浏览器专项：确认前无模型请求、只读与撤销、截断展示、设置变化使确认失效、真实引用 API 的更新/删除拒绝、取消迟到响应、旧结果、预算错误、切章隔离、正文变化、无密钥、正文长度边界、深色及 390px 窄屏、选区/滚动/实例保持。

所有数据库由测试在临时目录新建，浏览器测试入口显式隔离环境配置及数据目录，不加载 `.env`。Provider 使用注入 Mock 或本地 Mock transport；浏览器使用请求拦截，失效引用等拒绝路径使用隔离后端。

## 写作布局与统一主题

正文原先由 `.document` 的 `max-width:950px` 和 `align-self:center` 居中，标题却相对编辑面板使用固定边距；屏幕越宽，两者起点越容易分离。普通模式现改为容器铺满编辑面板，标题与正文共享 `--writing-inset`（桌面 32px，小屏 24px）。标准与紧凑布局的段落仍限制舒适行长，宽幅布局释放段落行长，均从左侧相同位置起笔。专注模式才将 850px 阅读容器居中，标题与其 754px 文本内容对齐，小屏共享 22px 内边距。390px 写作视图将已有导航排到编辑器上方，保留原有操作，避免强制 660px 画布。

AI 写作、引用、模型、对比、审阅和应用提示共用全局语义颜色变量。现有 `usePreferences` 仍负责浅色、深色、系统主题与跨标签页同步，不增加主题状态或刷新要求。所有颜色规则局限于 AI 组件；正文保存逻辑、Tiptap 数据结构及自动保存队列未变。

`writing-ui.spec.ts` 覆盖 2560/1440/1024/390px、标准/宽幅/紧凑布局及普通/专注模式，实际测量正文坐标、标题文本坐标、容器宽度和页面横向溢出；在真实第二标签页切换主题、模拟系统主题变化，核对 AI 各区域计算背景色、文字对比度与焦点样式。测试生成 PNG 截图和 `layout-measurements.json`、`theme-measurements.json`，随 GitHub Actions artifacts 发布。

“before”证据在同一虚构页面注入明确保存的历史受影响 CSS，属于历史规则复现，周边 UI 使用当前版本；“after”移除该复现样式后测量实际修复代码。截图不是生产用户内容，也不代表真实 Safari 人工验收。
