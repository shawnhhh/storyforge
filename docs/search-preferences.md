# 统一搜索与偏好设置

基于 main `be049d4` 独立实现，不依赖未合并的 PR #7。

## 统一搜索

在小说侧栏点击「统一搜索」；专注写作时可从顶部打开。输入后约 250ms 查询本机已保存内容，可按小说和类型组合筛选。搜索覆盖：

- 小说标题、简介；章节标题及 Tiptap 嵌套正文的纯文本。
- 人物名称、分类、标签、全部人物字段和发出的人物关系类型。
- 世界观名称、分类、标签、描述和时间文本。
- 大纲、剧情线、剧情卡片、伏笔的标题与详细内容，以及卡片摘要、故事时间。

中文与特殊字符按字面子串匹配，拉丁字母忽略 ASCII 大小写；不提供拼音、分词、模糊或正则匹配。标题命中优先，每页 50 条，随后按小说、类型、标题和 ID 稳定排序。结果显示来源、类型、内容片段和高亮；渲染为 React 文本，不解析作品中的 HTML。

点击结果打开对应小说、章节、具体人物 / 设定或规划条目。存在未保存修改、保存失败或操作进行中时，仍可检索，但禁止跳转，沿用已有草稿保护。关闭窗口后可继续保存或解决冲突。目标在另一窗口被删除时保留搜索窗口并显示错误，可重新搜索。

请求失败有重试按钮；修改输入会取消前次请求，迟到响应不会替换当前查询。Escape 关闭搜索并恢复原按钮焦点。对话框使用原生模态交互和键盘焦点约束，不新增与浏览器冲突的快捷键。

API：`GET /api/search?q=关键词&kind=chapter&novelId=UUID&offset=0`。`kind` 可选 `novel / chapter / character / world / outlines / plotlines / cards / foreshadows`；类型、小说范围和 offset 均可省略。返回 `{ hits, hasMore }`，每个 hit 含 `id / novelId / novelTitle / kind / title / excerpt`。空白关键词返回空集，关键词最长 200 字，offset 为 0–999999 的十进制整数；非法或重复参数返回 400。

搜索为 SQLite 参数化只读查询，直接读取既有数据表，不增加索引副本、不变更 schema、不触碰版本号或正文、不调用外部服务；响应设置 `Cache-Control: no-store`。当前使用子串扫描，适合本机作品库；超大型库若需优化，可在后续独立评估增量全文索引。

## 偏好设置

在侧栏或专注写作顶部打开「偏好设置」，变更即时应用：

- 主题：跟随系统 / 浅色 / 深色，跟随系统时监听系统外观变化。
- 正文字体：系统 / 宋体与衬线 / 等宽；使用系统字体栈，不下载远程字体。
- 正文字号：12–28 px；只影响显示，不修改富文本格式。
- 编辑器布局：标准三栏 / 宽幅正文 / 紧凑侧栏。已有「专注写作」继续独立工作。
- 快捷键提示：显示或隐藏章节导航中的提示，实际快捷键继续有效。

「恢复默认偏好」只重置这五项。设置使用带版本命名的 localStorage 键 `storyforge:preferences:v1`，同源标签页通过 storage 事件同步。浏览器存储不可用或空间不足时显示错误，当前页面仍可应用；损坏或非法值不会影响启动，未知字段不参与界面配置。

显示偏好按浏览器保存；Safari 与 Chrome 各自设置，不跨浏览器同步，也不包含在小说备份或导出中。作品及资料仍以 SQLite 为唯一数据源。此实现不新增或修改备份恢复模块、不更改已有迁移、不读取规划草稿键，不引入云服务。

## 验证

```sh
npm ci
npm run lint
npm run typecheck
npm run build
npm test
E2E_CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

单元测试使用 `:memory:` SQLite 和 Mock 存储；HTTP 测试只监听临时 loopback 端口。Playwright 沿用既有测试运行器，专用临时数据及备份目录，不读取 `.env`、不复用用户服务；网络失败、迟到响应、配额错误使用 Mock。测试覆盖跨小说筛选及精确跳转、嵌套正文、特殊字符、分页、删除、未保存草稿保护、偏好持久化、系统外观、标签页同步和编辑器 DOM 身份保持。

Mac Safari 仍需人工验收原生字体效果、系统外观切换、模态焦点、专注写作和宽窄窗口布局；自动化 E2E 使用 Chromium，不代表 Safari 已验收。
