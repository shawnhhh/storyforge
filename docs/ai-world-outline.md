# AI 世界观与小说大纲

入口：小说 → 创作规划 → AI 世界观与大纲。无需先创建章节。

1. 选择世界观、人物设定、分卷大纲或章节大纲，填写创作要求，选择现有模型和参数。
2. 可按需勾选本小说已保存的资料或章节（最多 8 项、总长度 1000–12000 字符）。默认不发送小说简介、原稿或资料库内容。分卷可归属总纲，章节大纲可归属分卷并关联已有章节；不会创建或修改正文。
3. 点击“核对发送内容”，检查完整 messages、模型参数、来源截断信息、token 与美元估算。预览不调用模型、不占请求预算、不写数据库。
4. 明确点击“确认发送并生成”，结果返回后只显示在可编辑预览中。可以取消请求、修改标题与完整内容、导出预览，或放弃重新设置。
5. 点击“确认新增保存”才写入数据库。世界观新增到“其他设定”，人物分类、标签及九个人物字段逐项新增到人物档案，预览内容作为补充备注；关系可使用已有资料库编辑器继续整理。分卷/章节大纲新增到原规划结构，保留选择的父级和章节关联。

不覆盖原有小说、章节、人物或设定。仅新增一项；没有批量自动写入、自动替换原稿或强制覆盖入口。世界观/大纲模型输出限定为 JSON `{"title":"标题","content":"完整内容"}`；人物额外必须包含 `character: {category,tags,fields}`，fields 为除 notes 外的全部既有人物字段，content 对应补充备注，未知字段、空内容、超长、截断、不完整 JSON 一律拒绝保存。内容始终作为文本渲染。

## 数据保护与限制

发送预览的 SHA-256 绑定请求、来源、完整本地基线、模型配置与参数。未预览或发生变化返回 409。所有未选资料仅在本机参与基线计算，不发送给模型。生成期间基线变化拒绝结果。

完成生成后服务端签发随机预览 ID，30 分钟有效，最多保留 100 项，过期或服务重启后不可直接保存，需导出并重新生成。每 2 秒和窗口恢复时核对预览有效性，失效时禁用保存但保留导出。保存时再次验证小说、所有人物/世界观/章节版本、规划版本及完整服务端模型配置/预算策略，检查父级和章节是否仍有效。相同预览与内容重复保存返回原结果，避免响应丢失后重试重复新增；已保存预览不可换内容重复新增。现有 generation 中间件继续防止重启/恢复后的旧请求写入。

资料使用原 `saveWorld` / `saveCharacter` 事务新增，大纲使用原 `PlanningStore.save` 乐观版本事务，在完整保留现有快照的基础上追加。没有另建存储或绕过原验证。保存失败保留可编辑、可导出的预览。保存进行中禁止关闭，响应超时需使用同一预览重试核对结果。

失败、取消和超时仍保留原预算预留，提供商可能已计费。报价未配置时显示费用未知，token/请求次数限制照常执行；报价估计不是实际账单。服务端按现有模型 timeoutMs 强制中止，前端生成等待上限 125 秒，预览/保存 15 秒。响应长度继续受 Provider 的 256KB 和 20000 字符上限限制。

预览为临时内存内容，不接入既有原稿自动保存队列；关闭预览明确提示放弃，支持 JSON 导出。刷新或浏览器崩溃可能丢失未确认预览，应及时导出或保存。批量多卷生成、自动人物关系确认、预览持久恢复与实际模型质量评估留待后续。

界面使用 Apple 风格系统字体、原生 modal、圆角及语义色；复用现有主题机制，支持浅色、深色及跟随系统实时切换。保存后刷新规划快照，焦点回到新的 AI 入口。

## 隔离验证

`npm test` 包含纯数据单元及真实 HTTP API Mock 测试；所有夹具使用虚构数据和临时 SQLite。

```sh
npm ci
npm run lint
npm run typecheck
npm run build
npm test
npx playwright install --with-deps chromium
npm run test:e2e -- --mock-planning --project=chromium
npm run test:e2e -- --project=chromium
```

新的 Mock 全链路 E2E 与原完整套件分别执行。`--mock-planning` 启动测试目录内专用组合根，要求独立临时目录且只注入 Mock Provider，不创建外部网络传输。生产入口没有 Mock 开关。默认原套件保持无真实 AI 密钥环境。两类 E2E 都清除 AI 环境配置，不加载 .env，不接触原 data/backup。

生产 Vite build 同样跳过 .env，避免构建读取真实配置。CI 新增 Linux Chromium、macOS Chrome 与 WebKit 的 AI 规划 Mock 专项；WebKit 自动化不等于原生 Safari 人工验收。

本轮结构化人物、模型变更失效、大库性能方法及 Chromium/Firefox/WebKit 验收见[专项验收报告](ai-world-outline-acceptance-20261020.md)。
