## 明确边界与待人工验收

- 单文件上限 128MiB，单 Studio 工程仍受导入 64MiB/单素材650KB规则约束；大于此范围的流式/分卷备份未实现。
- 浏览器草稿恢复到 SQLite 独立收件箱，可导出核对后手动采用；**没有自动回填原编辑器**，不会覆盖正在编辑的草稿。其他浏览器、未保护编辑、非 JSON 数值字段无损恢复未完成；备份前需先保存/导出。
- 选择作品恢复保留当前安装的全局 writing_settings、writing_days；其原值仍在备份中，但不自动合并计数或覆盖偏好。导入/恢复收据保存在备份中，不把旧收据作为本机已完成恢复操作复用。
- 只有 JSON 格式版本1可恢复；旧的“小说 sqlite 备份”继续走旧入口，不能伪称含 Studio。恢复时原正在运行的 Mock 任务继续作用于原项目，副本中未完成任务标记失败，需手动重试。
- SHA-256 检查损坏，不提供签名认证或加密；媒体声明类型白名单不等同编解码内容审计。
- 进程中断在提交前验证通过；真实硬件断电、文件系统故障、磁盘满、跨浏览器与真实 Safari 仍需验收。保持 Draft。
