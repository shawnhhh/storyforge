## 可运行交付

- Music/Video 共用服务端 `AsyncCreativeProvider`：模型能力声明、参数校验、幂等 submit、按 key lookup、poll、cancel、可选签名 Webhook 验证。默认仅注册本地 Mock bridge，无凭据、外部请求或付费路径。
- Studio SQLite 向前迁移至 v4，保留原工程、版本和素材；新增任务快照、模型、远端 ID、幂等摘要、截止时间、租约、重试与事件表。旧任务无远端协议时仍明确标失败，避免假称可恢复。
- 提交原子写入队列；提交/排队/运行/完成/失败/取消均持久保留。重复 key 同参数返回同任务，不同参数拒绝。每工程一个活动任务；worker 全库最多两个有效租约。
- worker 自动恢复到期租约；先 lookup 对账再 submit，同一远端幂等键保持不变；10 秒调用超时、30 分钟任务期限、最多四次暂时错误重试，指数退避与抖动。Provider 必须正确实现幂等和对账，真实供应商尚未验收。
- 事务内保存素材和完成状态；租约校验拦截旧 worker；取消立即拦截晚到结果，远端取消另行持久执行。有限重试失败留下明确错误和历史，不能保证供应商已停止收费。
- Webhook 必须由 Provider 验签，仅唤醒权威轮询，不采用回调的结果字节。默认 Mock 不启用 Webhook。仅该签名入口豁免浏览器世代头，仍保持现有 Host、Origin、JSON 和备份锁校验。公网回调转发部署不在本 PR 范围。
- Music/Video 提交附幂等键、可取消任务；刷新读取服务端任务。修复 Video 素材先于完成状态读取而导致预览永久缺失的竞态，保留原项目切换响应隔离。
- 原始工程内容独立于生成快照；生成只能新增素材，不能覆盖较新歌词或剧本。

## 自动化

新增七项隔离单元测试：幂等/快照、重启继续、提交响应丢失后对账、取消晚到结果、租约及截止时间、真实超时 AbortSignal 与错误脱敏、签名 Webhook。

原有迁移测试随 v4 更新：从真正旧表结构升级且原表内容完全一致、未来 v5 拒绝且内容/版本不改。原失败 Provider 测试替换 worker 前显式 stop，避免在同库同 Provider ID 下同时注册两个不同实现，未删除断言。

具体 head SHA、最终测试统计与 CI URL 记录于本 Draft PR 描述；不得将待运行 CI 写成通过。第一次本地 E2E 因 Playwright 浏览器缺失失败；下载被域名策略拒绝，改用已安装系统 Chromium，不绕过策略。随后发现并修复测试世代头缺失及 Video 完成/素材竞态；原失败记录保留在工作区日志与 trace 中，不提交大型产物。

## CI 首轮失败与修复

首轮 PR CI 40508759321 的 macOS Chrome Job 122204800227 在原有 API CRUD 测试首个写请求收到 423（预期 400）。日志确认启动监听/health 已就绪，但自动备份仍持写锁。BackupService.start 现在返回首次检查的 Promise，入口 await 完成后才 listen；不关闭自动备份、不重试业务写请求、不更改原断言。新增慢备份启动就绪合约测试；新 head 重新运行必要检查和九 Job。

首轮 Firefox 分片 2 Job 122204800242 另暴露资料关联旧 GET 覆盖已确认 PUT 的竞态。下载 artifact 12735914977 并核查 trace：PUT 返回 version=2 且包含关联，较早 GET 的 version=1 在其后完成，使 UI 列表丢失但数据库正确。KnowledgeLinks 改为拒绝较旧版本、每次 effect 独立失效标记；新增延迟初始 GET、成功添加关联后才放行的浏览器回归，保留原删除与布局断言。

## 剩余风险与下一阶段

本 PR 仅 A，尚未实现 B/C/D/E/F。媒体仍采用原 BLOB 和 650KB 上限。旧 JSON 工程/统一备份保留任务摘要和素材，不导出可重新执行的远端队列、快照或事件；导入/恢复未完成任务时标失败，绝不重新调用供应商。迁移后的库不可交由旧版本服务直接打开，应保留升级前副本。

B 下一步：内容寻址文件存储、数据库元数据与引用、分块上传/断点续传、受限下载恢复、流式 manifest 备份及完整校验后副本恢复；兼容原 JSON/BLOB，不覆盖现有作品。随后 C 实施服务端配置与密钥、价格估算/确认、预算预留与月限、重复计费防护及下载 SSRF/容器校验。在 B/C 稳定前不启用真实 Music/Video。D/E 继续使用协议 fixture 验证，供应商未选定不调用付费服务。

所有测试使用临时目录与隔离 SQLite；没有读取或覆盖真实数据库、作品、素材或备份。Mock WAV/WebM 仅证明流程，不代表真实 AI 质量或费用验收。无真实硬件断电、磁盘满或公网供应商回调验收。
