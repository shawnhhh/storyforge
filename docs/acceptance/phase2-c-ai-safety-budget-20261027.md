## 真实代码

- Studio v5→v6 增量表：报价确认、任务预算预留和月度索引。微单位整数记账；报价绑定完整项目快照/Provider/模型/价格，5分钟过期、单次消费。入队同一个 SQLite 事务内检查限额并预留，事务失败不留下任务、费用或消费确认。幂等重放在预算预留前返回原任务，网络重试不重复预留。
- 服务端能力与价格配置：`STORYFORGE_MEDIA_BUDGET_CONFIG` 可配置模型支持模块、最大提示词、时长、每秒微单位价格、单任务和月度上限；运行时验证且白名单序列化，浏览器不能传价格或提升预算。模型还需在异步 Provider registry 注册，配置价格不等于启用真实供应商。
- 默认只注册两个 Mock 模型：mock-v1 免费、mock-metered 每秒1000微虚拟单位。默认单任务100000/月度1000000；免费 Mock 保持已有行为，收费演示先报价、用户明确确认后才入队。取消确认不产生任务或预留。
- 完成按预留结算一次；失败/取消保守保留预留，避免远端可能已计费时错误退款。账本持久恢复，备份副本不复制/重放金融账本或报价确认；当前安装预算不被恢复绕过。
- ServerKeyVault 服务端 AES-256-GCM 加密文件，Provider ID 作为 AAD，目录0700/文件0600，主密钥由独立环境变量 `STORYFORGE_MEDIA_VAULT_MASTER` 提供32字节base64。无主密钥时禁用；不自动生成真实 Key，不提供浏览器读取/写入 Key 接口。服务端部署代码可调用 set/get；Provider API只暴露 keyConfigured 布尔值。Vault 不进入项目导出或统一备份，主密钥丢失无法解密，需另行安全保管。
- 通用递归脱敏处理认证字段、Bearer、常见Key/Token和URL查询；Express错误日志及启动错误接入脱敏。任务失败继续使用固定安全错误，不回传上游原文。
- SafeMediaDownloader：HTTPS精确域名白名单，拒绝用户密码、非443端口、尾点、IP字面量；所有DNS地址必须为公开unicast，阻断私网/loopback/link-local/metadata/IPv4映射IPv6/CGNAT等。连接使用已验证IP，Host/TLS证书仍绑定原域名；每次重定向重新验证，最多3跳，不转发凭据。
- 下载校验MIME、容量、SHA-256、容器头；只允许强ETag + If-Range + 精确Content-Range恢复。超时覆盖解析、请求和流读取，失败不发布结果，已有不同目标拒绝覆盖。签名URL不进入错误消息。发现通用代理无法保证DNS固定时默认失败关闭；必须提供经过审查的代理传输适配器，不能降低校验来放行。

## 自动化与边界

安全专项覆盖幂等费用、限额、取消保留、重启账本、过期/改稿/改价报价、二次结算、加密/错主密钥/篡改与脱敏、URL/DNS/IPv4/IPv6/重绑定、固定IP、非法重定向、下载中断续传/ETag变更/超时/类型容量哈希拒绝。浏览器覆盖虚拟费用拒绝确认、确认后生成与单次预留，原Music/Video/大媒体/统一备份继续回归。准确测试统计、SHA和CI链接记录于PR描述，未结束CI不得标通过。

所有数据库和Key均为隔离临时fixture，价格虚拟；不读取、不使用真实API Key，不调用付费接口。Vault提供服务端持久配置能力，未实现外部KMS、轮换后台或管理员Key管理UI。SafeMediaDownloader是供后续Provider调用的服务端适配入口，未开放任意URL下载HTTP接口，真实远端下载/代理和供应商计费尚未验收。失败预留释放需要后续真实供应商账单对账，当前采取保守不释放。Mock-metered按配置预估保留，不能作为真实模型费用证据。B 的同步大备份验证、磁盘配额与完整容器解码风险仍在。
