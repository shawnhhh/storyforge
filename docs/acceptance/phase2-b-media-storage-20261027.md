# B 阶段：大型媒体存储与统一备份 v2

基线固定为 #36 `bc3937f95b42df9d0fdffcae8d5d023e50924c51`，独立 B 分支，不改 #36、#35、main。云环境技能用于核查网络和环境。指定 CI 40510390211 的 macOS 两 Job 最终结论在 PR 描述记录；未结束不写作通过。

## 实现

- Studio v4→v5 增量迁移：新表保存 CAS 对象、项目引用、持久上传偏移；旧项目、历史与 BLOB 媒体原样保留。数据库只存新媒体元数据，文件存放于数据目录/media；权限目录 0700、文件 0600。
- 2GiB 单媒体、512KiB 分块，SHA-256 校验，重复同字节分块幂等，不一致拒绝；重启后查询已提交偏移，截掉未提交尾部。先校验并发布文件再事务提交引用，发布后 SQL 中断可由 CAS 文件恢复；失败只留下可回收孤儿，不覆盖原作。
- 内容哈希文件名，拒绝路径注入、符号链接和硬链接文件；MIME/容器魔数检查。相同内容共享对象，每个项目持独立引用；引用计数从引用表计算，不维护易漂移计数器。
- Range 下载/Content-Range 支持断网续传，独立校验接口返回 digest 与引用数。删除仅解除引用；GC 只删零引用且超过24小时的对象，上传和备份临时产物7天后清理。
- 统一备份 v2：旧项目 JSON 清单（含小说、音乐、视频历史与旧媒体）+ 去重 CAS 对象字节。导出流式写磁盘，下载支持 Range；备份导入同样可分块续传（32GiB 上限）。逐文件哈希、大小、文件头以及关系结构验证后才能预览确认；恢复原子插入全新项目/素材 ID，复用已验证 CAS 对象。失败保留原项目与引用，不执行归档的远端任务。
- Music/Video 均提供大型媒体上传、试听/预览、导出、解除引用及统一 v2 预览确认恢复。浏览器流式计算哈希（@noble/hashes），不一次读入整个大文件；重新选择同文件从已保存偏移继续。备份面向已保存作品，未保存编辑应先保存/导出。
- 原 JSON 和 BLOB 工程仍兼容；存在外置媒体时旧 JSON 导出明确要求 v2，不静默漏掉大文件。v1 JSON 恢复不接受未经文件校验的外置引用。

## 验证与故障分析

隔离测试覆盖3MiB文件、分块重放冲突、未提交尾部、恢复偏移、去重/引用/GC、哈希和文件头拒绝、Range 精确字节、v2副本恢复、损坏文件不写项目、SQL失败回滚及发布中断恢复。完整 lint/typecheck/build、单元/API、浏览器结果与 head SHA/CI URL 以本 PR 描述为准。

首次联合 E2E 有两类失败：新增空 status 造成原音乐断言歧义（改为有消息才渲染状态）；新大媒体测试留下外置引用，影响后续“旧 JSON 格式”测试前提（新测试结束只解除自己创建及恢复副本的引用）。原回归断言和质量门槛均保留。类型检查发现 HTTP JSON unknown 类型，补精确类型后重跑。

## 风险及后续 C

没有真实多GiB文件、磁盘满、硬件断电验收；实测用合成 WAV 与临时 SQLite，不上传媒体产物。旧 BLOB 与旧 JSON 元数据仍受原128MiB上限约束；v2大文件字节流不受该上限，但导入逐对象验证目前有同步文件读取，超大库可能阻塞本地服务，需后续 worker 优化。魔数校验不等于完整解码/防病毒。GC 为显式维护 API，未启动后台删除定时器。备份导出/预览耗用磁盘，暂未实现磁盘配额；遗留 BLOB 不做破坏性自动迁移。

C 从 B 精确 SHA 顺序派生：服务端密钥与脱敏、模型/价格配置、费用预览确认、事务预算预留与月限、幂等防重复费用，以及远端下载 URL/DNS/重定向/容量安全。所有费用虚拟、所有模型 Mock，不启用真实 Key 或付费服务。
