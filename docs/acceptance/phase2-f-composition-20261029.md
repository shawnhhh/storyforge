## 功能与边界

视频工作台新增“章节→分镜”：只读取已保存章节，Mock 按段落产生可预览的场景、镜头及字幕，确认后创建唯一命名的新视频工程。最多20段、单段2000字、总计12000字；超限明确拒绝，不静默截断。不是语义大模型导演能力。预览 token 五分钟有效、最多100份，绑定章节完整快照；章节改变或删除后拒绝旧确认。重复确认同一 token 只返回原副本，取消不写入。

每个场景可编辑名称、设定及角色引用；每个分镜可编辑场景、描述、运镜、时长、角色及顺序。只允许来源小说中的角色；已经删除的原有引用保留历史追溯，不能当作新引用添加。视频任务预览展示实际发送的镜头、场景与已选角色上下文，绑定工程和角色版本；确认后使用现有持久队列追加免费 Mock 任务。任务插入、预算预留、分镜 taskIds 与历史版本在同一 SQLite 事务完成，失败全部回滚。已有任务及结果不被替换；用户明确选择哪个任务或素材进入时间线。

`settings.composition` 是共享、版本化 schema 1：来源章节快照、scenes、shots、tracks。统一整数毫秒时间基准，视频/音乐/配音/字幕轨，片段有开始、持续、素材偏移、音量和分镜/场景锚点。轨内重叠拒绝，跨轨可以混音；视频主轨仅一条，最多8轨、单轨200片段、总时长10分钟。只有本机数据库中的 asset/media/task ID 可以成为素材源，不执行工程中的 URL 或路径。镜头锚点片段随镜头排序移动；场景锚点保持显式时间，改镜头时长后需手动核对片段排布。

编辑带本机草稿、旧草稿手动核对恢复、下载草稿和版本冲突保护。不同编辑区域互斥保存，避免旧工程配置覆盖未保存的分镜。原小说、角色和原有音乐/视频素材只读引用；生成和恢复都追加新内容。

## 本地预览与受控导出

先保存有效时间线，再同步预览 Canvas 视频/字幕及音乐、配音。支持播放、暂停、拖动、静音、偏移和音量；短视频保持末帧，短音频结束后静音。视频原声静音，音频必须显式关联独立音乐/配音轨。缺失、未完成或不能解码的媒体不能启动导出；不依赖远程模型。

本地实时导出先显示计划、再确认：Canvas.captureStream + Web Audio 混音 + MediaRecorder 输出 WebM VP8/Opus，固定640×360、15fps，最多30秒/30片段/20MiB。页面后台、主动取消、解码/录制错误、墙钟超限会中止；不会上传、覆盖素材或自动导入成片。预览最多64个媒体片段，更多需拆分。浏览器不支持 WebM 录制时禁用并说明，仍允许本地预览，不编造 MP4/ProRes 等导出能力。浏览器导出测试验证下载的 WebM 容器与 Opus 音轨。

这是受控短片导出，不是专业无损离线渲染：实际音画同步、帧率、字体和编码依赖浏览器/硬件；不保证逐帧确定性、复杂效果或多视频叠加。Playwright WebKit 不等于 Safari 原生应用；WebKit 仅在真实支持相应录制能力时测试导出，否则验证明确的禁用边界。

## 引用、备份与恢复

保存及统一恢复都验证当前工程和历史版本的媒体/任务引用、MIME、内部场景/分镜 ID 和时间边界。被当前时间线、分镜任务或历史引用的 CAS 媒体不能解除引用，防止 GC 破坏可恢复历史。

联动工程及带联动历史的工程拒绝单项目导入/导出，要求统一备份。统一恢复按新副本重映射跨项目素材、任务及来源 ID；漏选被引用的音乐模块时拒绝并回滚所有副本，不自动指向原素材。选择小说模块才能重建活动小说引用；未选小说仅保留历史来源快照，不自动恢复/改写现有小说。未完成任务恢复为失败，不自动重发。沿用统一媒体备份 v2 的文件长度、SHA-256 和 CAS 验证。

将 E 的 Hailuo receipt 表声明放入统一 Studio schema，兼容旧备份缺表，备份清空可执行 receipt；解决 Provider 开关导致暂存库表集合不一致的问题。未改变小说冻结 schema、Key Vault 或安全下载器约束。

## 自动验证

- 新增核心测试：预览不写入/确认幂等、来源过期、整数/重叠/排序/角色作用域、角色变更、任务与预算事务回滚、CAS/历史引用保护、跨模块恢复 ID 重映射与漏选回滚、重启及拒绝单工程悬空导入。
- 联动浏览器专项：预览取消、场景/镜头编辑排序、刷新草稿恢复、分镜任务确认/结果、配音混轨与字幕预览、受限 WebM 下载、来源与项目版本冲突、390px布局。全部临时数据。
- 完整单元/API、本地 lint/typecheck/build；保留完整 Chromium/Firefox/macOS Chrome/WebKit 回归和 Music3/Hailuo/费用专项，新增四平台 Composition 协议工作流。最新 SHA 的精确结果见 PR，不以旧 head 的结果作最终结论。

## 跨浏览器修复记录

Firefox headless 首次录制回归失败，进一步诊断为音频 `OnMediaSinkAudioError`，视频无错误；CI为Linux Firefox配置每runner临时PulseAudio空输出设备，提供真实音频时钟，不静音、跳过或放宽断言。播放器区分设备失败与解码失败，仍中止错误导出。另修复暂停时每帧重复seek，旧BLOB素材接口支持单字节范围、后缀、416及If-Range，保留CSP/nosniff与原下载器校验。失败运行和修复后准确SHA结果记录在PR中。

## 剩余风险

Mock 分镜需人工校订，没有验收真实导演模型、TTS 或商业成片。没有拖拽波形、自动节拍对齐、转场/交叉淡化、嵌入式视频原声提取或长片服务器渲染。来源删除后保留历史引用会显示过期提示；要再次发送角色上下文需修复引用。历史引用保守保留媒体，可能增加磁盘占用。极大跨模块档案、硬件断电、磁盘满、长时间播放、浏览器解码资源峰值和跨设备录制质量尚未实测。真实付费 Provider 在本轮未启用。
