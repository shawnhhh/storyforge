# 真实 AI Music / Video 接口开发方案（验收后的下一阶段）

本文件是开发拆分，不表示真实接口已接入或已验收。当前 Studio 使用 Mock；启动真实接口开发以总集成最新 SHA 的完整 CI 通过为门槛。

## 架构与实施顺序

保留现有 `CreativeProvider`、Studio 项目/版本/素材，以及独立 `studio.sqlite`。真实远端生成通常是长任务，不能直接把当前内存 Mock 定时任务替换成一次长 HTTP 请求。先扩展服务端任务协议：提交、查询、取消、能力查询，保存 provider/model、远端 job ID、请求幂等键、项目版本快照、超时/重试、费用预留和最终消耗。API key 只在服务端读取，浏览器不保存或导出凭据。

1. **供应商与协议确认**：分别选一个有正式音乐/视频 API、文档与测试凭据的供应商；确定模型、输出格式、时长/尺寸、价格、地域、内容使用条款、数据保留和异步机制。交付能力/价格配置与错误映射；不把非官方网页接口作为正式 API。
2. **持久任务基础设施**：新增向前兼容迁移和 provider registry；实现服务重启后的远端对账、轮询退避、并发限制、取消、截止时间、429/5xx 处理。提交用幂等键，网络断开后先查询再重试，避免重复扣费。项目编辑与任务快照独立；过期结果只能作为该项目的新素材，不能覆盖新歌词/剧本。
3. **安全与预算**：复用小说 AI 预算理念，但单独增加媒体时长/分辨率费用估算、确认发送内容、单任务与会话硬上限。日志和错误脱敏；下载只允许供应商配置域名，校验重定向、超时、容量、MIME 与实际容器格式，防止 SSRF 和异常大文件。
4. **Music 垂直切片**：歌词、曲风、情绪、BPM、结构映射到已选 API；提供生成前内容和估价预览、任务进度、失败重试、试听与完整工程导出。用协议 fixture 覆盖歌词/纯音乐及参数不支持场景，不静默丢参。
5. **Video 垂直切片**：剧本、分镜、镜头时长、比例和引用素材映射到已选 API；先单镜头生成，再实现明确的多镜头编排。素材上传需逐项确认；保留分镜到远端任务/输出的关系，避免把单镜头样片标成整片制作。
6. **媒体存储和备份升级**：当前单素材约650KB、工程64MiB、统一备份128MiB，只适合 Mock，不能直接支持真实长音视频。设计内容寻址文件存储 + 数据库元数据，下载临时文件校验后原子发布，备份使用 manifest/哈希/分卷或流式 ZIP；恢复先完整校验再发布副本。保持旧 JSON 可导入，补充中断、孤儿文件清理、磁盘不足和跨库事务失败测试。
7. **界面和可观察性**：模型能力驱动输入限制；展示真实费用状态、排队/运行/取消/失败/结果、供应商 request ID（脱敏），与历史版本分开。默认仍为 Mock 或关闭真实生成；通过配置显式启用。
8. **发布验收**：Codex 完成 lint/typecheck/build、迁移、合约、失败注入、并发、草稿、备份恢复和跨浏览器 CI；随后在明确的小额预算内，用专用测试工程运行各一个真实 Music/Video 请求及失败/取消检查。没有供应商、凭据或额度时，真实接口验收明确标未验证。

## 建议独立 Draft PR 拆分及依赖

| 顺序 | PR 范围 | 依赖 | 自动化通过标准 |
|---|---|---|---|
| A | Provider 协议、能力配置、持久任务迁移 | 总集成通过 | 旧库升级/新版拒绝不改数据；任务重启对账；幂等提交 |
| B | 媒体文件存储和备份 v2 | A 的素材契约 | 大文件流式限制、字节哈希、恢复为副本、失败回滚、旧格式兼容 |
| C | 服务端密钥、预算、出站下载安全 | A | 脱敏、预算拒绝、429/超时/取消、SSRF 与重复计费防护 |
| D | 真实 Music adapter + UI | A/B/C，供应商已定 | 合约 fixture + Mock E2E；受控真实音频可播放且可恢复 |
| E | 真实 Video adapter + 单镜头 UI | A/B/C，供应商已定 | 分镜关联、异步任务与媒体下载；受控真实视频可播放且可恢复 |
| F | 多镜头编排、整体验收和启用说明 | D/E | 全量九 Job、新 SHA、受控真实请求记录；默认开关与回滚验证 |

每个 PR 独立验收，不修改现有来源 PR，不合并 main。真实请求的费用、延迟与质量需测量后再估算产品 SLA；当前不作供应商能力或完成日期承诺。
