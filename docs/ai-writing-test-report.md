## 执行记录与限制

PR #7 的首次 push CI 出现人物 CRUD 用例同毫秒时间戳与随机 UUID 导致的排序假设失败（PR CI 同文件树通过）。已用限定作用域的固定时钟覆盖碰撞，改为完整数组及正确排序断言，新增固定 UUID/时间戳回归；人物测试文件以 4 个并发进程重复 30 次、共 240 项检查全部通过。完整 `npm test` 为 76/76，E2E 为 37/37；lint、typecheck 和 build 通过。此次修复没有改生产排序、工作流、超时标准，也未跳过测试。详见 [CI 不一致排查报告](ci-test-consistency.md)。

开发中先完成 9 项 AI 浏览器测试；完整回归期间继续编辑触发了 Vite 热更新及一次页面重载，导致保存等待失败。通过 trace 确认重载后，停止修改源码，补齐至 11 项 AI 流程，再完整执行最终套件。最终结果以上表为准。浏览器套件整体时间上限从 240 秒调整为 360 秒以容纳新增场景，单项 45 秒限制保持不变。

未执行真实服务商 API 或 macOS Safari/Firefox 手工测试，因此不声称验证模型质量、供应商计费或这些浏览器的原生对话框行为。模型服务必须支持非流式 OpenAI Chat Completions 与 `max_tokens`。取消 HTTP 请求不保证远端不计费；返回文本仍须作者审阅。接受结果以纯文本替换选文内部格式；选区外格式保留。详细数据范围及配置见 [ai-writing.md](ai-writing.md)。
