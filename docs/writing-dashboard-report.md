## 交付内容

- 首页展示作品概览、作品字数与章节正文进度、总字数、最近五个编辑章节，以及指定章节继续写作入口。
- 每日目标可编辑并持久化，支持超额完成；连续写作、最长连续天数及最近 14 天足迹均来自真实成功保存记录。
- 复用既有小说/章节接口、小说弹窗、按钮、字体与编辑器；字数计算提取到共享模块，避免前后端统计口径分叉。
- 简洁卡片布局，跟随系统深色模式；桌面四列概览，手机两列概览与单列内容。验证无横向溢出，底部内容可滚动访问。
- 保留未保存草稿、保存失败、版本冲突及备份操作期间的离开保护；保留切换作品时当前的规划或资料模块。
- schema v3 仅新增每日增量与目标两表，纳入原子备份恢复；章节保存与增量记录同事务，失败不会留下虚假记录。

## 统计边界

每日统计按 UTC 自然日；只累计成功保存时的字数正增量，删除不扣除，等字数替换与格式变化不计入。旧章节不回填历史，删除后重写可能再次累计。章节没有既有“完成”状态，因此展示“已有正文 / 总章节”。旧备份恢复后新增历史为空、每日目标取默认值。详见[完整功能说明](writing-dashboard.md)。

## 数据安全与交付范围

单元/API 测试使用内存数据库或 `mkdtemp` 临时目录；E2E 单独启动服务，覆盖数据及备份路径，不加载 `.env`，退出后清理临时数据库。没有打开或迁移仓库 `data/` 中的真实 SQLite，没有读取真实小说正文，也没有上传测试数据库、用户数据或密钥。

依赖按现有 lockfile 安装，无新增项目依赖。只提交、推送本功能分支，并创建目标为 main 的 Draft PR；不合并、不启用自动合并、不部署。
