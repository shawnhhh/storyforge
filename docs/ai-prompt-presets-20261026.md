# AI 写作提示词模板增量

## 缺口与实现

核对 #19–#24 后，模型配置、上下文引用、续写/改写/润色、生成规划、明确预览写入、手动重试、取消超时、预算与结果 usage 均已存在。本轮只补齐尚无入口的写作要求模板，不重复实现 Provider、预算或存储。

独立分支基于 #24 `5fc17182858be0df98351e7fa906f121cf469c04`，与连接恢复 PR #25 相互独立。新增六个内置模板，覆盖五类现有写作操作：场景续写、悬念续写、保留口吻润色、感官扩写、对话改写、三种后续走向。

选择模板仅展示完整文本。用户点击「用模板替换写作要求」才替换原要求，随后可以继续编辑；不自动附带资料、不改变写作操作、不生成或写入正文。切换操作时不可应用上一操作的模板，手写要求保留。生成过程中沿用原 fieldset 禁用保护。文本复用全局主题、表单样式与可访问名称，适用于窄屏。

未新增自定义模板存储/导入功能；模板仅为可编辑写作建议，不能保证模型遵循或解决一致性问题。只在原有「生成预览」动作中使用用户最终确认的要求；API Key、模型接口仍须显式服务端配置，测试全部 Mock。

## 验收与边界

新增桌面1440px、移动390px两条端到端回归：选择不覆盖手写要求；明确应用；应用后可编辑；切换操作保留要求并使旧模板不可应用；仅显式生成才有一个 Mock 请求；请求 action/instructions/上下文开关正确；关闭预览后原文保持、章节 PUT 数为零。既有接受/自动保存/撤销、取消、失败重试、预算、引用与主题回归仍保留。现有 CI 自动在 Chromium、Firefox、macOS WebKit 执行该完整写作文件。

lint/typecheck/build、完整单元/API、数据专项、Chromium AI 写作专项的最终计数与提交 SHA 见 PR 描述；不使用其他分支 CI 替代本提交结果。真实系统 IME、Safari/iPhone 与真实模型质量仍待人工验收。

只运行临时 SQLite/备份、隔离浏览器和 Mock AI，不读 .env、密钥或真实用户资料；不增依赖、数据表、迁移或云同步。不修改 main/#19–#25 原分支、不合并、不启用自动合并，保持 Draft。
