## 已交付

统一搜索覆盖小说、章节正文、人物、世界观，以及大纲 / 剧情线 / 卡片 / 伏笔。支持小说与类型组合筛选、标题优先、50 条分页、内容片段、高亮及精确条目跳转。中文和特殊字符按字面检索，嵌套富文本和跨行内格式的连续文字均可匹配。未保存草稿或操作期间禁止跳转；目标删除、请求失败和迟到响应有对应保护。

偏好设置支持系统 / 浅色 / 深色主题、三类本机字体、12–28 px 字号、标准 / 宽幅 / 紧凑布局及快捷键提示开关。设置即时应用、持久化并同步同源标签页；支持恢复默认、非法值回退和存储失败提示。字体和字号变化保持现有正文编辑器 DOM，不写入作品格式。

保留既有 Apple 风格布局和原生模态焦点管理；小说与资料仍由本机 Express + SQLite 保存。偏好属于浏览器外观配置，独立使用版本化 localStorage 键，不与规划草稿混用。
