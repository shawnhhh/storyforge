## 功能与复用

- 统一管理人物、地点、势力组织、力量体系、历史事件及其他设定，提供类型、角色分类、全文搜索和标签组合筛选。

- 保持本机 Express + SQLite 与原有 macOS 风格；新增 v3 增量迁移、独立关联版本、事务校验及删除清理。
- JSON 导出与备份包含全部资料和引用；旧备份在私有副本中升级，事务恢复失败回滚，恢复前引用保留在安全快照。
